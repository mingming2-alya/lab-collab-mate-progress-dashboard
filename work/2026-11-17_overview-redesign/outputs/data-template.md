# 總覽頁資料範本（每週填一次）

每個案例填一段，交給 PM 彙整。新版總覽頁會依這些欄位自動畫出「階段推進」與「里程碑進度條＋本週增量」。

## 填寫說明

- **類型**：決定這個案例走哪一套成熟度階段。
  - 研究型：研究 → 試點 → 推廣 → 結案
  - 交付型：規劃 → 開發 → 驗證 → 上線
- **上週／本週階段**：從上面挑一個。本週有往前推進，頁面會用箭頭標出。
- **里程碑**：把整個案例拆成 **4–8 個**可驗收的里程碑，全部列出。已完成的打勾並寫完成日期，未完成的寫預計日期。
  - 進度條＝已完成數／總數。**本週完成的**會用另一個顏色標出，這就是「本週增量」。
  - 各案拆的粒度要接近，否則進度條之間不好比較。
- **本週完成事項**：每項一行，寫「做完了什麼」，不寫「正在做什麼」。越具體越好，例如「雷達定時監控完成，已打包成 app」。
- **需要副總支援**：沒有就留空。有的話寫清楚「要什麼、什麼時候前要」。
