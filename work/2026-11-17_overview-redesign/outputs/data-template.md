# 每週進度：訊息範本

**做法**：PM 每週用訊息問各需求的負責人，對方直接回訊息，不填表格、不開檔案。
PM 把收到的回覆貼給 Claude，Claude 對應到各需求、**標出空泛的回答並建議追問句**，再更新總覽頁。

- 每則訊息 **4 題**（沒有數字的推廣型 3 題），編號回答即可，手機上一分鐘內回完。
- 同一位負責人管好幾個需求時，**合成一則訊息**問。
- 沒有變動可以只回「同上週」。
- 寫數量時用「4 個、共 12 個」，不要寫「4/12」（會被看成日期）。

## 每週訊息（依需求類型）

### 交付型：照步驟做出一個東西

```
【週報｜{需求名稱}】{週次，例：11/17–11/23}
1. 本週做完了什麼？（1–2 件，寫結果）
2. 現在做到哪一步？{步驟選項}
3. 下週要完成什麼？（1–2 件，寫完成的樣子）
4. 需要副總幫忙嗎？（沒有回「無」）
```

> 有子項的需求（例如客戶軟體驗證有 Bundle、proxima、EFI），第 2 題請**每個子項各回一句**；有數量的順便寫，例如「Bundle：節點開發，完成 6 個、共 10 個」。

### 研究型：回答一個問題

```
【週報｜{需求名稱}】{週次}
1. 本週做完了什麼？（1–2 件，寫結果）
2. 目前結論是什麼？（一句話；還沒有結論就寫「測試中，已測 __ 項」）
3. 下週要完成什麼？（1–2 件，寫完成的樣子）
4. 需要副總幫忙嗎？（沒有回「無」）
```

### 推廣型：讓更多人用

有明確數字可追的（目前只有 AI Hiring Agent）：

```
【週報｜{需求名稱}】{週次}
1. 本週做完了什麼？（1–2 件，寫結果）
2. 本週數字：尋求單位 __ 個、申請單位 __ 個、已上線單位 __ 個
3. 下週要完成什麼？（1–2 件，寫完成的樣子）
4. 需要副總幫忙嗎？（沒有回「無」）
```

沒有適合數字的（Codio 工具腳本類、Codio 大型系統類）只問 3 題；使用情況的回饋之後由另一個專門統計推廣平台使用的系統提供：

```
【週報｜{需求名稱}】{週次}
1. 本週做完了什麼？（1–2 件，寫結果；有新的使用團隊或案例也寫在這裡）
2. 下週要完成什麼？（1–2 件，寫完成的樣子）
3. 需要副總幫忙嗎？（沒有回「無」）
```

## 範例

**問（交付型，有子項）**

```
【週報｜客戶軟體驗證】11/17–11/23
1. 本週做完了什麼？（1–2 件，寫結果）
2. Bundle、proxima、EFI 各做到哪一步？（設計規劃／節點開發／首次跑通／五次跑通／用戶驗收／上線）
3. 下週要完成什麼？（1–2 件，寫完成的樣子）
4. 需要副總幫忙嗎？
```

**回**

```
1. Bundle 正式數據首次跑通全流程；proxima 新增 2 個自動化節點
2. Bundle：首次跑通。proxima：節點開發，完成 4 個、共 8 個。EFI：節點開發，完成 1 個
3. Bundle 連續五次跑通；proxima 首次跑通
4. 無
```

**合併問（一位負責人管多個需求）**

```
【週報】11/17–11/23，請依需求回答：
A. 驗證兩台　B. 驗證四台
每項回：1. 本週做完了什麼　2. 目前結論　3. 下週要完成什麼　4. 需要幫忙嗎
```
