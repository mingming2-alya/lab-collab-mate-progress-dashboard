## 使用者口述

## 簡報重點

- 題目：Codio 在 IDE 插件與原生 TUI 中的體驗差異。
- **結論**：最大差異在「代碼 ⇄ 對話」的連接，插件讓選中、引用、跳轉一氣呵成。「插件把交互變成看得見，TUI 把操作留在鍵盤上。」

| 維度 | IDE 插件 | 原生 TUI |
|---|---|---|
| 上手 | 按鈕、下拉選單，幾乎零學習 | 斜線命令＋快速鍵 |
| 多會話 | 多標籤並行，互不打斷 | 一次一個會話，靠切換 |
| 閱讀輸出 | Markdown 渲染、思考可折疊、Diff 卡片 | 字元介面捲動 |
| 審批與問答 | 彈窗卡片、分步表單 | 行內鍵盤確認 |
| 選中代碼 | 選取後自動帶入當上下文 | 感知不到編輯器 |
| 引用檔案 | @ 模糊搜尋，顯示為檔案標籤 | @ 搜尋，純文字路徑 |
| 跳回代碼 | 點擊直達對應行，對比視圖看改動 | 要自己去找檔案 |

- **產出**：IDE 插件安裝 SOP（5 步）：準備環境（安裝並登入 Codio）→ 安裝插件（擴充市場搜尋、重啟 IDE）→ 首次設定（Opencode Path 改成 codio）→ 設定模型（新增自訂模型 codio-model）→ 開始使用（選中代碼提問、多標籤並行）。
